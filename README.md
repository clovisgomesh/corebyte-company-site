# 🚀 CoreByte Tech Solutions | Site Institucional

Bem-vindo ao repositório oficial do site institucional da **CoreByte Tech Solutions**, uma empresa especializada em desenvolvimento web, inteligência artificial, ciência de dados, mentorias e educação tecnológica.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as melhores práticas do mercado de desenvolvimento front-end:

* **HTML5 Semântico:** Estrutura limpa, acessível e otimizada para motores de busca (SEO).
* **CSS3 Modular:** Organização avançada com uso de variáveis (`:root`), Flexbox, Grid Layout e estilização responsiva.
* **JavaScript Moderno (ES6+):** Manipulação de eventos, interatividade de menu mobile e animações de scroll.
* **Intersection Observer API:** Sistema nativo para animações fluidas de entrada ao rolar a página.
